# Татьяна Чушкова

## QA Engineer | Manual QA | API | SQL | Mobile Testing | Performance Testing | Python Automation

Развиваюсь в направлении QA Engineer, изучаю и применяю на практике различные подходы и инструменты тестирования программного обеспечения.

Работаю с функциональным, регрессионным, позитивным и негативным тестированием, тестовой документацией, REST API и базами данных. Составляю чек-листы и тест-кейсы, анализирую требования, проверяю граничные значения, оформляю баг-репорты.

Осваиваю мобильное тестирование Android-приложений, включая ручное тестирование и автоматизацию UI-тестов с использованием Espresso, UI Automator и Appium.

Изучаю нагрузочное тестирование: разработку профилей нагрузки, подготовку сценариев и планов тестирования, мониторинг производительности и аппаратных ресурсов системы.

Развиваю навыки автоматизации тестирования на Python с использованием Selenium WebDriver и Pytest. Также имею практику работы с JavaScript-инструментами автоматизации: Cypress, Playwright, Puppeteer и Jest.
